## Exercícios de Lógica de Programação

Aqui estou compartilhando exercícios que vou fazendo ao longo do tempo para treinar lógica de programação enquanto curso Análise e Desenvolvimento de Sistemas.

Espero que, da mesma forma que esses exercícios estão me ajudando, eles também possam ajudar outras pessoas que estão passando pelo mesmo processo.

Alguns exercícios são mais chatos por conta da dificuldade, outros são mais simples e divertidos. Faz parte do aprendizado.

Mas peço apenas uma coisa: se você está aqui, provavelmente quer evoluir na área. Então, não abuse da IA para resolver esses desafios.

Eu e você sabemos que a IA "sabe" programar. A questão é provar para você mesmo que **você também sabe**.
