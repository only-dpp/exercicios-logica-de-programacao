# Reajuste Salarial

Uma empresa decidiu reajustar o salário de seus funcionários de acordo com o cargo.

Faça um algoritmo que receba o salário atual e o código do cargo do funcionário. Com base no código informado, calcule o valor do aumento e o novo salário.

| Código | Cargo          | Aumento |
| -----: | -------------- | ------: |
|      1 | Serviço Gerais |     50% |
|      2 | Vigia          |     30% |
|      3 | Recepcionista  |     25% |
|      4 | Vendedor       |     15% |

### Exemplo

Entrada:

```text
Digite seu salário aqui: 2000
Digite o código do seu cargo: 3
```

Saída:

```text
+ Cargo: Recepcionista(3)
+ Valor do aumento: 500.0
+ Salário novo: 2500.0
```
