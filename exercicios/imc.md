# Cálculo de IMC

Faça um algoritmo que receba a altura e o peso de uma pessoa, calcule seu IMC e informe sua classificação.

Utilize a fórmula:

```text id="wq3j6m"
IMC = peso / altura²
```

### Classificação

|           IMC | Classificação          |
| ------------: | ---------------------- |
|      Até 18,5 | Abaixo do peso         |
| 18,6 até 24,9 | Peso ideal             |
| 25,0 até 29,9 | Sobrepeso              |
| 30,0 até 39,9 | Obesidade grau I ou II |
| Acima de 39,9 | Obesidade              |

### Exemplo

Entrada:

```text id="5j8h2m"
Digite sua altura: 1.75
Digite seu peso: 70
```

Saída:

```text id="f5q9zc"
22.857142857142858
Você está com o seu peso ideal.
```
