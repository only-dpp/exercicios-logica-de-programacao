# Aprovação de Alunos

Faça um algoritmo que receba a quantidade de alunos de uma turma e, para cada aluno, informe seu código e sua nota final.

Considere que o aluno está **aprovado** caso sua nota seja maior ou igual a `7` e **reprovado** caso sua nota seja menor que `7`.

Ao final, informe a quantidade de alunos aprovados e reprovados.

### Exemplo

Entrada:

```text
Informe o numero de alunos: 3

Informe o código do aluno: 101
Digite a nota do aluno: 8

Informe o código do aluno: 102
Digite a nota do aluno: 5

Informe o código do aluno: 103
Digite a nota do aluno: 7
```

Saída:

```text
aluno 101 recebeu nota: 8.0

aluno 102 recebeu nota: 5.0

aluno 103 recebeu nota: 7.0

numero de alunos aprovados: 2
numero de alunos reprovados: 1
```
