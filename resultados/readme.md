# Enviando sua solução

Esta pasta é destinada para quem quiser compartilhar suas soluções dos exercícios.

Se você resolveu algum exercício e quer contribuir com o repositório, siga o padrão abaixo.

## Como enviar

1. Crie uma pasta com seu nome ou usuário.

```text
resultados/
└── seu-nome/
```

2. Dentro dela, coloque os arquivos para cada exercício que você resolveu.

```text
resultados/
└── seu-nome/
    ├── algoritmo.md
    ├── calculo-salarial.md
    └── imc.md
```

Você pode utilizar a linguagem que preferir.

## Como contribuir

Você pode enviar sua solução por meio de um **Pull Request**.

Não é necessário resolver todos os exercícios. Envie apenas aqueles que você quiser compartilhar.

Antes de enviar, confira se:

* sua solução corresponde ao exercício correto;
* os arquivos estão dentro da pasta correta;
* os nomes dos arquivos estão organizados;
* sua solução pode ser entendida por outra pessoa.

## Importante

Não publique apenas uma solução pronta sem tentar entender o exercício.

O objetivo desta pasta é compartilhar diferentes formas de resolver os mesmos problemas e aprender com as soluções de outras pessoas.

Se você está começando, tente resolver primeiro sozinho. Depois, compare sua solução com a de outras pessoas(se tiver.)
